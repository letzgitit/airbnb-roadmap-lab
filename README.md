# airbnb-roadmap-lab

에어비앤비 관련 기획 흐름과 실행 로드맵을 정리하기 위한 단일 HTML 실험 프로젝트입니다.

## Status

- Type: lab
- Visibility: private
- Stack: HTML

## What It Does

- 에어비앤비 서비스/분석 아이디어를 로드맵 형태로 시각화합니다.
- 별도 빌드 도구 없이 정적 HTML로 바로 확인할 수 있습니다.

## Project Structure

- `index.html`: 로드맵 화면

## Run Locally

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속합니다.
