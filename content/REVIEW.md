## 3. 확인 못 한 것

- 공중위생관리법 개정 뒤 플랫폼 과태료 금액: 시행일(2026.11.12)과 법률 번호는 확인. 500만 원은 시행령 입법예고 보도뿐이라 공식 칸에 금액을 넣지 않음.
- 9/7 발의 법안(요금 신고·예약취소 금지·50배 과징금)과 5/27 발의 법안(조례 등록 기준): 보도로만 확인. 국회 의안정보시스템 원문은 못 열었음. updates.json에 「발의 단계」로만 적음.
- 요금표 위반 처분 단계(5일·15일·1개월·취소): 시행령 개정이유는 법령정보센터에서 확인, 처분 단계 숫자는 보도(뉴시스) 기준. 시행령 별표 원문은 못 열었음.
- 문체부 2025.10.10 지침 본문(hwp): 게시 사실만 확인. 내용 요약은 위홈 안내 기준.
- 외도민 사업자의 부가세 과세 유형: 1차 출처 확인 못 함.
- 위홈의 「2026년 5월 임시허가 전환」: 위홈 자체 공지뿐이라 넣지 않음.
- 동대문구 안내문(볼트 사본)의 노후 기준: 공개 URL을 찾지 못해 공식 칸에 넣지 않음.
- 톡방 사례 중 「특례→외도민 전환 때 사업자 재발급 불필요」「관광기금 융자 심사 강화」「소방·구청 실사 2회인 구」: 한 사람의 말이라 「확인 필요」로 표시.
- 서울 외도민 공급 수치(7천여 곳): 볼트 자체 집계와 보도 숫자가 조금 달라 숫자를 넣지 않음.

## 4. 개인정보·강의명 점검

- 넣지 않은 것: 개인 계약 건의 주소·호수, 소유자·공유자 이름, 생년월일, 보증금·월세 금액, 계좌, 등기부 내용, 지인 이름, 톡방 닉네임·전화번호, 숙소 주소, 강의명·강사명·수강 모임명·강의 플랫폼명.
- 공무원 담당자 이름은 넣지 않음(종로구 안내문의 팀 전화번호도 넣지 않음).
- 강의 정리 노트 문장은 옮기지 않고 요지만 다시 씀. 출처 표시는 `"from": "강의 요령"`.

```

$ grep -rnE "<톡방 닉네임·방장 사이트 이름 목록>" content/ ; echo "exit $?"

$ python3 -c "import json;[json.load(open(f)) for f in ['content/steps.json','content/scripts.json','content/updates.json']];print('ok')"
```

금지어 목록은 작업 지시에 있는 그대로 썼고, 이 파일 안에서도 걸리지 않도록 단어를 적지 않았다.

## 5. 앱 쪽에 알릴 것

- `steps.json` 각 단계에 스키마 외 필드 `start`, `end`(숫자 Day), `type`(기존 차트 색 분류: prep·milestone·critical·setup·admin·open)을 넣었다. 기존 타임라인 차트를 그대로 그리는 데 쓰면 된다.
- 10단계(사진)는 공식 기준이 없어 `official`이 빈 배열이다.
- 공식 항목의 출처 이름이 길다. 화면에서는 `region` + `source` 앞부분만 보여 주고 링크로 연결하는 편이 낫다.

- 외도민이 국내에 외국인 등록을 하고 머무는 사람(F-1-D 등)을 「외국인 관광객」으로 받을 수 있는지, 28박 이상 숙박이 숙박업이 아닌 임대로 보일 소지가 있는지: 관광진흥법·문체부 지침에서 공식 근거를 찾지 못해 warnings에 넣지 않았다. 구청에 물어볼 일이다.
- 에어비앤비 도움말의 「관할 지역에 따라 한 달 이상 숙박하면 게스트가 임차인 지위를 얻을 수 있다」는 문장이 한국 법에서 어떻게 적용되는지.
- 에어비앤비 주간 할인의 「7박 이상」 기준은 이번에 도움말 원문으로 다시 확인하지 못했다(기존 문장 그대로).

점검(2026-10-19): JSON 로드 통과, 추가한 official 2건 url·checked 있음, 고친 6·7·10·11단계는 상한 안, 금지어 grep 0건.

## 9. 단계 창 개편 · 참고 자료(2026-10-19)

### 탭이 5개로 바뀜
- 할 일 · 주의사항 · 규정 · 노하우 · 참고 자료. 예전 「경험담」 탭은 없애고 「노하우」 탭 안으로 합쳤다. 노하우(`tips`) 줄을 먼저, 이어서 「실제 사례」(`community`) 묶음을 따로 보인다. 사례 줄은 본문 아래에 겪은 날짜를 달고, 칩은 「주의」(빨강)나 「질문」 같은 값(회색)일 때만 단다(「사례」는 칩 없음).
- 데이터 필드 `tips` · `community` 는 그대로다. 합치기는 화면에서만 한다. 검색도 두 필드를 모두 노하우 탭으로 연결한다.
- 「참고 자료」 탭은 0 개여도 늘 보이고(빈 상태 문구), 0 개일 땐 숫자 배지를 달지 않는다. 다른 탭은 0 개면 숨긴다.

### `refs` 필드 규격 (`content/steps.json` 단계마다, 없으면 빈 목록)
`{ title, summary, source, date, url, kind, auto? }`
- `kind` 는 `기사` · `영상` · `공지` 중 하나, `date` 는 `YYYY-MM-DD`, `url` 은 원문 주소(화면에서는 http(s)만 링크).
- 글자 수 상한은 자동 자료에만 건다(제목 160 · 요약 300 · 출처 40). 고정 항목은 사람이 쓰므로 검사하지 않는다.
- `auto` 는 자동 수집 항목에만 붙는다(고정 항목에는 쓰지 않는다). 화면에 「자동 수집」 글자가 붙고, 자동 항목이 하나라도 있으면 목록 위에 「자동으로 모은 자료는 틀릴 수 있어요」 안내가 뜬다.
- 줄 모양: 제목(링크, 끝에 화살표 아이콘) → 요약 → 출처 · 날짜 · (자동이면) 자동 수집. 종류 칩과 「원문 보기」 링크는 없다(`kind` 는 데이터에만 남는다).

### 7단계 디지털노마드(F-1-D) 줄을 규정에서 참고 자료로 옮긴 이유
이 줄은 도시민박업 등록 규정이 아니라 「한 달 이상 머무는 손님을 노릴 때 참고할 배경 정보」다. 규정 탭에 있으면 지켜야 할 규칙처럼 읽혀서, 같은 보도자료를 7단계 참고 자료(고정 항목, 종류 「공지」)로 옮기고 규정 탭에서는 뺐다. 내용(최대 3년 체류)은 8절에서 대조한 그대로다.

### 자동 자료
- 출처: 데일리의 `/api/oedomin-refs`(주소는 환경변수 `REFS_FEED_URL`로 바꿀 수 있고, 빈 값이면 끈다). 응답은 `{ version: 1, updated, steps: { "<단계 번호>": [항목…] } }`.
- 읽기: 서버에서 6시간(21600초)마다 다시 받는다(홈 화면 ISR). 재배포 없이 갱신된다. 배포 빌드 때 못 받으면 고정 항목만으로 화면을 만들고, 운영 중 6시간마다 다시 만들 때 못 받으면 앞서 만든 화면(그때 받은 자동 자료 포함)을 그대로 둔다(`lib/refs.ts`, 서버 로그에 경고 한 줄).
- 검사: 단계 번호는 1~14 정수, 원문 주소는 https 만, 글자 수 상한, 날짜 형식, 종류 세 값, 단계당 40개까지만 읽는다. 항목 하나가 틀리면 그 항목만 버린다.
- 합치기: 고정 + 자동을 주소 기준(앞뒤 공백 · `#…` · 끝 `/` · `www.` · `utm_*` 무시)으로 중복 제거(고정이 이김), 날짜 내림차순(같으면 고정 먼저), 단계당 30개 상한.

### 엉뚱한 자동 자료 빼는 법
`content/refs-block.json` 의 `urls` 에 그 자료의 원문 주소를 넣고 배포하면, 그 자료가 모든 단계에서 빠진다(고정 항목에도 적용된다). 주소는 위 정규화 기준으로 비교한다.
